# エキストラノート プライバシーポリシー

制定日：2026年9月23日  
改定日：2026年10月4日

「エキストラノート」（以下「本アプリ」）は、利用者の情報を以下の方針に基づいて取り扱います。

## 1. 本アプリで保存する情報

本アプリは、利用者が入力または選択した以下の情報を端末内に保存します。

- 氏名、ふりがな、生年月日、性別
- 電話番号、最寄り駅
- 身長、靴のサイズ、身体寸法
- 作品名、募集情報、応募状況
- 撮影日、集合時間、終了時間、撮影場所
- 参加記録、キャスト名、メモ
- 利用者が選択した写真
- 地図検索で選択した場所、住所、緯度、経度

iCloudを利用できる場合、保存した記録、関連情報、個人プロフィール、参加写真の原本を、AppleのCloudKitプライベートデータベースへ自動同期します。同期した情報は、同じApple Accountを使用する端末間で共有され、アプリ再インストール後の復元にも使用されます。iCloudの保存容量を使用します。

開発者が管理するサーバーへの保存や、本アプリ独自のアカウント登録は行いません。iCloudを利用できない場合も、端末内への保存は継続します。

## 2. 募集情報の解析

本アプリは、Apple Intelligenceの端末内モデルを利用して募集情報を解析します。解析対象の文章や文字認識のための画像を、解析目的で開発者が管理するサーバーへ送信しません。

利用者が解析結果を募集情報として保存した場合、その情報は第1項に記載したiCloud同期の対象になります。

## 3. カメラの利用

本アプリは、募集情報を画像から読み取る目的でカメラを利用します。

撮影画像は文字認識処理に使用し、写真として永続保存しません。画像から認識した文章を利用者が募集情報として保存した場合、その文章は端末内に保存され、iCloudを利用できる場合は同期されます。

## 4. 写真の利用

利用者は参加記録へ写真を追加できます。写真の原本は端末内のアプリ専用領域に保存され、iCloudを利用できる場合はCloudKitへ同期されます。表示用サムネイルは端末内に保存し、iCloudへ同期しません。

写真に撮影日時や位置情報などのメタデータが含まれる場合、その情報も原本の一部として保存・同期される場合があります。本アプリは、参加写真を広告事業者へ提供しません。

## 5. 地図検索

本アプリは、撮影場所の検索および地図表示にApple MapKitを利用します。

地図検索時、検索語句や地図利用に必要な情報がAppleへ送信される場合があります。Appleによる情報の取り扱いは、[Appleプライバシーポリシー](https://www.apple.com/jp/legal/privacy/)を参照してください。

本アプリは端末の現在地を取得しません。利用者が選択して保存した場所、住所、座標は、第1項に記載したiCloud同期の対象になります。

## 6. 広告配信

本アプリは、広告配信のためGoogle Mobile Ads SDK（Google AdMob）を利用します。

Google Mobile Ads SDKは、広告配信、広告効果測定、不正防止、サービス改善などの目的で、以下の情報を自動的に収集または処理する場合があります。

- IPアドレスから推定されるおおよその位置情報
- 端末識別子またはアプリ固有の識別子
- 広告の表示、クリックなどの広告データ
- アプリ内での操作情報
- クラッシュ情報、パフォーマンス情報、診断情報
- 端末およびOSに関する情報

Googleによる情報の取り扱いは、[Googleプライバシーポリシー](https://policies.google.com/privacy?hl=ja)および[Googleによる広告でのデータ使用](https://policies.google.com/technologies/partner-sites?hl=ja)を参照してください。

## 7. 広告に関する同意

本アプリは、Google User Messaging Platform（UMP）を利用して、欧州経済領域、英国、スイスなど、同意取得が必要な地域の利用者へ広告関連の同意画面を表示する場合があります。

対象地域では、利用者の選択内容に応じて広告を配信します。同意が必要であり、有効な同意状態を確認できない場合、広告配信を開始しません。

同意内容を変更できる場合、本アプリ内に「広告プライバシー設定」を表示します。

本アプリは、App Tracking Transparencyによるアプリ横断トラッキングの許可を要求しません。
