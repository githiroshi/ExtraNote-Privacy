# エキストラノート プライバシーポリシー

制定日：2026年9月23日

「エキストラノート」（以下「本アプリ」）は、利用者の情報を以下の方針に基づいて取り扱います。

## 1. 本アプリで保存する情報

本アプリでは、利用者が入力または選択した以下の情報を端末内に保存します。

- 氏名、ふりがな、生年月日、性別
- 電話番号、最寄り駅
- 身長、靴のサイズ、身体寸法
- 作品名、募集情報、応募状況
- 撮影日、集合時間、終了時間、撮影場所
- 参加記録、キャスト名、メモ
- 利用者が選択した写真
- 地図検索で選択した場所、住所、緯度、経度

これらの情報は、AppleのSwiftData、UserDefaultsおよびアプリ専用ストレージを利用して端末内に保存します。

開発者が管理するサーバーへの送信、アカウント登録、CloudKitによる同期は行いません。

## 2. 募集情報の解析

本アプリは、Apple Intelligenceの端末内モデルを利用して募集情報を解析します。

解析対象の文章は端末上で処理され、開発者が管理するサーバーへ送信されません。

利用者が貼り付けた文章や、カメラ画像から読み取った文章は、利用者が保存操作を行った場合に募集情報として端末内へ保存されます。

## 3. カメラの利用

本アプリは、募集情報を画像から読み取る目的でカメラを利用します。

撮影画像は文字認識処理にのみ使用し、写真として永続保存しません。ただし、画像から認識した文章は、利用者が保存操作を行った場合に募集情報として端末内へ保存されます。

## 4. 写真の利用

利用者は参加記録へ写真を追加できます。

選択された写真は、原本および表示用サムネイルとして端末内のアプリ専用領域へ保存されます。本アプリがこれらの写真を開発者または広告事業者へ送信することはありません。

写真に撮影日時や位置情報などのメタデータが含まれる場合、その情報も原本の一部として端末内へ保存される場合があります。

## 5. 地図検索

本アプリは、撮影場所の検索および地図表示にApple MapKitを利用します。

地図検索時、検索語句や地図利用に必要な情報がAppleへ送信される場合があります。Appleによる情報の取り扱いは、Appleのプライバシーポリシーを参照してください。

- [Apple プライバシーポリシー](https://www.apple.com/jp/legal/privacy/)

本アプリは端末の現在地を取得しません。

## 6. 広告配信

本アプリは、広告配信のためGoogle Mobile Ads SDK（Google AdMob）を利用します。

Google Mobile Ads SDKは、広告配信、広告効果測定、不正防止、サービス改善などの目的で、以下の情報を自動的に収集または処理する場合があります。

- IPアドレスから推定されるおおよその位置情報
- 端末識別子またはアプリ固有の識別子
- 広告の表示、クリックなどの広告データ
- アプリ内での操作情報
- クラッシュ情報、パフォーマンス情報、診断情報
- 端末およびOSに関する情報

Googleによる情報の取り扱いは、以下を参照してください。

- [Google プライバシーポリシー](https://policies.google.com/privacy?hl=ja)
- [Googleによる広告でのデータ使用](https://policies.google.com/technologies/partner-sites?hl=ja)

## 7. 広告に関する同意

本アプリは、Google User Messaging Platform（UMP）を利用して、欧州経済領域、英国、スイスなど、同意取得が必要な地域の利用者へ広告関連の同意画面を表示する場合があります。

対象地域では、利用者の選択内容に応じて広告を配信します。同意が必要であり、かつ有効な同意状態を確認できない場合、広告配信を開始しません。

同意内容を変更する必要がある場合、本アプリ内に「広告プライバシー設定」を表示します。

本アプリは、App Tracking Transparencyによるアプリ横断トラッキングの許可を要求しません。

## 8. 第三者への提供

開発者は、利用者が本アプリへ入力または保存した個人情報を取得せず、第三者へ販売または提供しません。

ただし、広告配信に伴い、Google Mobile Ads SDKが前述の情報をGoogleおよび広告配信事業者へ送信する場合があります。

また、地図検索に伴い、検索に必要な情報がAppleへ送信される場合があります。

## 9. 情報の保存期間と削除

利用者が入力した情報は、利用者が削除するまで端末内に保存されます。

募集情報、参加記録、写真などは、本アプリ内の削除機能から削除できます。

氏名、電話番号などの個人情報は、各入力欄から削除または変更できます。

本アプリを端末から削除すると、本アプリが端末内へ保存した情報も削除されます。ただし、端末バックアップにデータが含まれている場合、バックアップの管理方法に従って保持される場合があります。

## 10. セキュリティ

本アプリは、iOSのアプリサンドボックス内に情報を保存し、他のアプリから直接アクセスできないよう保護します。

ただし、端末の紛失、第三者による端末ロック解除、端末バックアップの管理状況などにより、情報が漏えいする可能性を完全には排除できません。端末のパスコードや生体認証の設定を推奨します。

## 11. 子どものプライバシー

本アプリは、子どもを主な対象として提供するアプリではありません。

## 12. プライバシーポリシーの変更

機能追加、利用サービスの変更、法令改正などに応じて、本ポリシーを変更する場合があります。

重要な変更がある場合、本ページまたはアプリ内で通知します。
